# Abdul Qadir Khan — Portfolio

A modern, responsive, and playful developer portfolio for **Abdul Qadir Khan**, Junior Software Engineer & Agentic AI Developer. Built with React 19, TypeScript, Vite, Tailwind CSS v4, and Motion.

## 🚀 Features

- **Kinetic & Playful UI**: Doodles, retro sticker aesthetic, smooth tilt effects, and custom interactive cursor.
- **Smooth Scrolling**: Integrated with [Lenis](https://github.com/darkroomengineering/lenis) for silky smooth inertia scrolling.
- **Motion Animations**: Built using `motion/react` with spring transitions and staggered entrance animations.
- **Showcase Sections**:
  - **Hero**: Interactive 3D tilt card, live terminal animation typing Qadir's stack, and quick CTAs.
  - **Projects**: Real-world projects including YTFactory (Autonomous AI Video Engine), Synthox AI (Multi-Agent platform), Jarvis AI, Todo App with Chatbot, Humanoid Robotics Book, and more.
  - **Skills**: Software tools and technologies chip matrix with interactive hover physics.
  - **About Me**: Interactive expandable background summary, stats counter, and social links.
  - **Contact**: Direct communication cards with mailto and call actions.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) & [GSAP](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ or v20+)
- [pnpm](https://pnpm.io/) (or npm / yarn)

### Installation

```bash
pnpm install
```

### Development

To start the local development server:

```bash
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

To build the static application for production:

```bash
pnpm build
```

To preview the production build locally:

```bash
pnpm preview
```
